# Python Fundamentals

This repository marks the beginning of my Python fundamentals series. I am
following a structured path from the basics to advanced Python concepts,
building practical examples as I learn.

## Learning Path

The series will cover:

- Python syntax and fundamentals
- Variables, data types, numbers, and strings
- Conditional statements and loops
- Functions and modules
- Lists, tuples, sets, and dictionaries
- File handling and exceptions
- Object-oriented programming
- Advanced Python concepts and projects

## Current Example

The current example demonstrates:

- Importing a function from another Python file
- Reading input from the user
- Passing an argument to a function
- Returning and displaying a result

Run the example with:

```bash
python login.py
```

Enter `Hassan` to see the valid username message. Any other input produces
the invalid username message.

## Goal

The goal of this series is to develop a strong understanding of Python
fundamentals and gradually apply that knowledge to more advanced programs
and real-world projects.
